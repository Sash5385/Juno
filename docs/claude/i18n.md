# Локалізація (uk основна; en, pl, de, es, fr)
- Рушій: `src/i18n/index.js` (обидва репо) — DOM перекладається на льоту за `dict.json` `{ "<uk>": {en,pl,de,es,fr} }`. Шаблони `{0}`; динамічний текст писати одним template-string, щоб збігся з ключем.
- Мова: `?lang=` → localStorage `dp_lang` → мова браузера. Перемикач `LangSwitch.jsx`. Мова користувача пишеться в БД (`src/i18n/syncLang.js`) для серверних сповіщень (`functions/i18n.cjs`).
- Нові рядки: `node scripts/extract-i18n.mjs` → порівняти з dict.json → додати переклади.
- Напрям послуг (`src/terms.js`) міняє «запис→сеанс» тощо; `toBase()` повертає слова для пошуку в словнику.
- Лендинг: `landing/js/i18n.js` + `landing/js/i18n-data.js`.
- Терміни: майстер = specialist / specjalista / Profi / profesional / pro; запис = booking / wizyta / Termin / cita / rendez-vous.
